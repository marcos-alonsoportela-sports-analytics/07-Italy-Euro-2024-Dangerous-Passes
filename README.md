# Italy — Dangerous Passes Analysis | UEFA Euro 2024

Analysis of Italy's most dangerous passes during UEFA Euro 2024 using event data and pitch visualizations.

## Overview

This project analyses the most dangerous passes made by Italy during UEFA Euro 2024.

The analysis uses event data to identify and visualise passing actions considered particularly relevant from an attacking perspective.

## Objectives

- Analyse Italy's passing activity during UEFA Euro 2024.
- Identify dangerous passing actions.
- Explore where these passes occurred on the pitch.
- Visualise the spatial distribution of dangerous passes.
- Apply event-data analysis to a real international tournament.

## Methodology

The analysis follows a spatial and event-based approach:

1. Load and prepare event data.
2. Filter Italy's passing actions.
3. Identify passes meeting the selected criteria for dangerous actions.
4. Analyse their starting and ending locations.
5. Visualise the resulting actions on a football pitch.

## Tools

- Python
- Pandas
- Matplotlib
- mplsoccer
- Jupyter Notebook

## Data

Event-based football data from UEFA Euro 2024.

## Output

The final visualisation shows the spatial distribution of Italy's most dangerous passing actions during the tournament.
